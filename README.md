# Лабораторная работа по статистике

Выполнена Беловой Еленой Игоревной

Для запуска необходимо иметь установленным (и занесенным в PATH) python, а также pip.

### Установка marimo и зависимостей
`pip install marimo pandas numpy scipy matplotlib seaborn`

### Запуск в режиме реактивного редактора:
`marimo edit lab01_marimo.py`

### Или запуск в режиме чистого веб-приложения:
`marimo run lab01_marimo.py`

Перенос оформления в marimo, а также код выполнен с помощью Gemini Argon 4.
